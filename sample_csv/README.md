# 가상 카드 내역 CSV (시뮬레이션용)

모두 **가상 데이터**예요. 월렛미러 시작 화면에서 CSV를 올리고, **월 소득을 70만원**으로 두면 아래 결과가 나와요.
(최근 3개월치: 2026-08 ~ 2026-10, 분석 기준 달은 마지막 달인 10월)

| 파일 | 판정 유형 | 지출(10월) / 소득 대비 | 위험도 | 이런 걸 확인해 보세요 |
|---|---|---|---|---|
| `01_배민VIP형_배달폭주.csv` | 🛵 배민 VIP형 | 56.7만 / 81% | 🔴 위험 | 배달 65%, 매달 지출이 늘어 1년 안에 적자 |
| `02_구독수집가형_정기결제6개.csv` | 📺 구독 수집가형 | 34.8만 / 50% | 🟢 안전 | 구독 6개 → **정리 추천** 로직 |
| `03_월말파산형_월초몰아쓰기.csv` | 📉 월말 파산형 | 48.1만 / 69% | 🟡 주의 | 지출의 96%가 1~10일에 몰림 |
| `04_카페지박령형_하루두잔.csv` | ☕ 카페 지박령형 | 43.4만 / 62% | 🟢 안전 | 카페 결제 59건, 비중 48% |
| `05_쇼핑도파민중독형_택배폭탄.csv` | 🛍️ 쇼핑 도파민 중독형 | 47.1만 / 67% | 🟡 주의 | 쇼핑 66%, 단건은 10만 원 미만 |
| `06_짠테크형_속세단절.csv` | 🐿️ 속세 단절 짠테크형 | 14.0만 / 20% | 🟢 안전 | 줄일 곳이 적은 알뜰형, 현금 비중 15% |
| `07_Flex한방형_항공권결제.csv` | 💸 Flex 한방형 | 45.9만 / 66% | 🟡 주의 | 항공권 28.5만 원 한 번이 지출의 62% |
| `08_인싸모임러형_밥약술약.csv` | 🎉 인싸 모임러형 | 47.7만 / 68% | 🟢 안전 | 식비(술자리·밥약) 62% + 문화 17% |
| `09_적자위험형_소득초과.csv` | 🛍️ 쇼핑 도파민 중독형 | **124만 / 177%** | 🔴 위험 | 소득보다 더 쓰는 경우의 경고 문구 (경계 사례라 쇼핑·배달 점수가 비슷함) |
| `10_형식제각각_자동분류테스트.csv` | 🛵 배민 VIP형 (경계) | 47.1만 / 67% | 🟡 주의 | **카테고리 컬럼 없음** → 자동 분류 33건, 날짜·금액 형식 혼합(`2026.10.01`, `"5,600원"`), 환불·빈 줄 3건은 건너뜀, 1개월치라 증가율은 가정값 |

위 표의 판정·금액은 월렛미러의 분석 로직으로 실제 돌려서 확인한 값이에요.
`09`, `10`은 두 유형 점수가 가까운 경계 사례라, 유형 판정 기준(`js/logic.js`의 `classifyType`)을 바꾸면 결과가 달라질 수 있어요.

## 소득을 바꿔 보면
소득은 위험도와 일부 유형 판정에 영향을 줘요. (위 표는 70만원 기준으로만 확인했고, 다른 소득으로는 따로 돌려 보지 않았어요.)
- 위험도: 1년 뒤 누적 잔액이 마이너스면 🔴, 소득을 넘는 달이 생기거나 지출이 소득의 80%를 넘으면 🟡, 아니면 🟢
- 유형 판정 규칙: 지출이 소득의 40% 이하면 짠테크형이 우선이고, 60% 이상이면서 지출이 월초(1~10일)에 몰리면 월말 파산형이 될 수 있어요.

## 파일 형식
```
날짜,사용처,금액,카테고리,결제수단
2026-10-03,배달의민족,18500,배달,카드
```
- 필수: 날짜, 사용처, 금액 / 선택: 카테고리, 결제수단(카드·현금)
- 카테고리: 식비, 배달, 카페, 교통, 쇼핑, 구독, 문화, 기타
- UTF-8(BOM 포함)이라 엑셀에서도 한글이 안 깨져요.

`generate_samples.ps1` 은 이 파일들을 만든 스크립트예요. (PowerShell로 실행, 프로필의 건수·금액을 고치면 새 유형 데이터를 만들 수 있어요)
