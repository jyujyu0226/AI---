AI로 쉽게 만드는 방법은 페이지 맨 아래 'CSV 파일 만드는 법'을 보세요.

📝 CSV 파일 만드는 법

⚠️ 카드 내역에는 개인정보가 있으니 카드번호, 계좌번호는 지우고 사용하세요.
AI에 붙여 넣기 전에 카드번호·계좌번호·승인번호·이름을 먼저 지워 주세요.

  1. 카드사 앱·홈페이지에서 이용내역을 열어 복사하거나 엑셀로 내려받아요.
  2. 아래 프롬프트를 복사해서 ChatGPT, Claude 같은 AI에 붙여 넣고, 맨 아래 [내 내역] 자리에 이용내역을 붙여 넣어요.
  3. AI가 만들어 준 CSV 내용을 메모장에 붙여 넣고 내역.csv로 저장해요. (인코딩: UTF-8)
  4. 현금으로 쓴 돈은 같은 형식으로 한 줄씩 추가하고, 위에서 파일을 올리면 끝!
AI에게 보낼 프롬프트 
아래 [내 내역]에 붙여 넣은 카드/현금 사용 내역을 CSV로 바꿔 줘.

[규칙]
1. 첫 줄은 정확히 이 헤더로 써 줘: 날짜,가맹점,금액,결제수단,메모
2. 날짜: YYYY-MM-DD 형식 (예: 2026-11-05). 시간은 빼 줘.
3. 가맹점: 가게·서비스 이름 그대로. 이름 안에 쉼표(,)가 있으면 공백으로 바꿔 줘.
4. 금액: 숫자만 써 줘 (쉼표, "원", 공백 없이). 지출은 양수, 취소·환불은 음수 (예: 12500, -12500).
5. 결제수단: "카드" 또는 "현금" 중 하나만.
6. 메모: 가게 이름으로 알 수 있으면 거래 종류를 한 단어로 적어 줘 (식사, 배달, 커피, 교통, 쇼핑, 구독, 문화, 게임, 운동, 병원 중 하나). 모르겠으면 비워 둬. 메모 안에는 쉼표를 쓰지 마.
7. 한 줄에 거래 하나씩. 제목, 합계, 요약 줄은 넣지 마.
8. 카드번호, 계좌번호, 승인번호, 이름 같은 개인정보는 넣지 마.
9. 설명 없이 CSV 내용만 코드 블록 하나로 보여 줘.

[예시]
날짜,가맹점,금액,결제수단,메모
2026-11-01,스타벅스 강남역점,5600,카드,커피
2026-11-02,진미옥,9000,현금,식사
2026-11-03,무신사,-39000,카드,쇼핑
2026-11-04,(주)한국정보통신,15000,카드,

[내 내역]
(여기에 이용내역을 붙여 넣으세요)

이 형식(날짜,가맹점,금액,결제수단,메모)은 월렛미러가 그대로 읽을 수 있어요. 카드사에서 받은 CSV를 바로 올려도 대부분 자동으로 인식해요.
